# AGENTS.md

## Project

Project name: Parfum

Parfum is a premium digital perfume boutique built with Laravel.

The main objective of this project is not only to sell perfumes, but to create a premium digital experience inspired by Apple's design philosophy.

---

## Development Philosophy

Always prioritize:

- Clean Code
- SOLID Principles
- Maintainability
- Scalability
- Readability
- Simplicity

Every implementation should feel production-ready.

Avoid unnecessary complexity.

---

## Architecture

- Laravel
- Blade
- MVC
- Reusable Blade Components whenever possible.
- Keep Controllers thin.
- Business logic must never live inside Blade views.
- Respect Laravel conventions.
- Avoid duplicated code.

---

## UI Philosophy

The website must feel premium.

Inspired by Apple's product pages.

Prioritize:

- elegant layouts
- whitespace
- smooth animations
- responsive design
- accessibility
- visual hierarchy

Animations must improve the experience.

Never add animations just because they look nice.

---

## Design Rules

Colors:

- Matte Black
- White
- Gold
- Dark Gray

Overall feeling:

Luxury

Elegance

Minimalism

Premium Quality

---

## Coding Rules

Before implementing any feature:

1. Analyze the project.
2. Understand the existing architecture.
3. Reuse existing components whenever possible.
4. Modify the minimum amount of code required.
5. Never introduce breaking changes.

---

## Components

Prefer reusable Blade Components.

Avoid duplicated HTML.

Keep views organized.

---

## Code Quality

Prefer readability over clever code.

Prefer explicit code over implicit behavior.

Avoid premature optimization.

Follow Laravel Best Practices.

---

## Frontend

Responsive by default.

Desktop-first design.

Mobile must remain fully usable.

---

## Git

Each implementation should be focused on one feature.

Avoid mixing unrelated changes.

---

## When requirements are unclear

Never guess.

Ask questions before implementing.

---

## Final validation

Before considering a task complete, verify:

- No syntax errors.
- No broken routes.
- No duplicated code.
- Responsive layout.
- Maintainable implementation.
- Clean project structure.
