# MVP (Minimum Viable Product)

# Proyecto

Parfum

Versión 1.0

---

# Objetivo del MVP

Construir la primera versión pública de Parfum enfocada completamente en la experiencia del cliente.

El objetivo NO es vender inmediatamente.

El objetivo es demostrar el concepto, validar la experiencia de usuario y construir una base sólida sobre la cual evolucionará el proyecto.

La prioridad será la calidad del diseño, la experiencia visual y una arquitectura escalable.

---

# Objetivos de la Primera Versión

La versión 1.0 deberá permitir:

- Conocer la marca.
- Explorar perfumes.
- Descubrir nuevos aromas.
- Comparar perfumes.
- Aprender sobre perfumería.
- Navegar en una experiencia premium.

No se desarrollará aún la parte administrativa.

---

# Alcance

La versión 1.0 incluirá únicamente el Frontend del cliente.

Toda la información deberá provenir de la base de datos.

No existirán datos escritos directamente en Blade.

Toda la información será administrable desde futuras versiones.

# Principios Técnicos

Durante el desarrollo del MVP se deberá cumplir:

- Código limpio.
- SOLID.
- Laravel Best Practices.
- Blade Components reutilizables.
- Arquitectura organizada.
- Responsive.
- SEO.
- Accesibilidad.

---

# Principios de Diseño

Toda pantalla deberá cumplir:

- Mucho espacio en blanco.
- Fotografías protagonistas.
- Animaciones elegantes.
- Excelente legibilidad.
- Colores premium.
- Componentes reutilizables.
- Diseño consistente.

Nunca deberá sentirse saturada.

---

# Componentes Base

Desde la primera versión deberán construirse componentes reutilizables para:

- Navbar.
- Footer.
- Botones.
- Cards.
- Badges.
- Títulos.
- Carruseles.
- Secciones.
- Inputs.
- Buscadores.
- Filtros.

Todos los componentes deberán mantener la misma identidad visual.

---

# Datos Dinámicos

Toda la información visible al usuario deberá almacenarse en la base de datos.

Ejemplos:

- Hero.
- Eslogan.
- Historia.
- Misión.
- Visión.
- Valores.
- Categorías.
- Marcas.
- Perfumes.
- Fotografías.
- Acordes.
- Pirámides.
- Redes sociales.
- Información de contacto.
- Instagram.
- Reseñas.

No deberán existir textos "quemados" dentro del código.

---

# Criterios de Éxito

La versión 1.0 será considerada exitosa cuando:

- El usuario quiera seguir navegando.
- El diseño transmita lujo.
- La navegación sea intuitiva.
- El sitio funcione correctamente en dispositivos móviles.
- La arquitectura permita seguir creciendo sin reescribir el proyecto.

# Objetivo Final del MVP

La primera versión de Parfum no busca competir con grandes plataformas de comercio electrónico.

Busca demostrar que una experiencia digital elegante puede hacer que descubrir perfumes sea tan emocionante como probarlos en una boutique física.

Cada decisión tomada durante el desarrollo deberá acercarnos a ese objetivo.
