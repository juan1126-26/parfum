# UI GUIDELINES

## Proyecto

**Nombre:** Parfum  
**Versión:** 1.0  
**Tipo de interfaz:** Boutique digital premium de perfumería

---

# Propósito del documento

Este documento define los principios visuales y de experiencia de usuario que deben mantenerse en toda la plataforma Parfum.

Su objetivo es garantizar que todas las páginas, componentes, animaciones y contenidos transmitan una identidad coherente, elegante y premium.

Estas directrices deberán aplicarse tanto al sitio público como, con las adaptaciones necesarias, al futuro panel administrativo.

---

# Visión de diseño

Parfum debe sentirse como una experiencia digital de lujo.

La principal inspiración visual es la filosofía de las páginas de producto de Apple:

- Diseño limpio.
- Jerarquía visual clara.
- Fotografías protagonistas.
- Animaciones suaves.
- Excelente uso del espacio.
- Textos breves y contundentes.
- Interacciones naturales.
- Atención cuidadosa a cada detalle.

La inspiración no implica copiar componentes, páginas o estilos exactos.

Parfum deberá construir una identidad propia asociada con:

- Perfumería.
- Lujo.
- Elegancia.
- Misterio.
- Exclusividad.
- Sensualidad.
- Confianza.
- Sofisticación.

---

# Principios fundamentales

## 1. El producto es el protagonista

Los perfumes y sus elementos visuales deben ocupar el centro de la experiencia.

La interfaz no debe competir con las imágenes del producto.

Los elementos decorativos deben reforzar la presentación del perfume y nunca distraer al usuario.

---

## 2. Menos elementos, mayor impacto

No se deben llenar las pantallas con información innecesaria.

Cada sección debe tener un mensaje principal y una acción clara.

Es preferible mostrar menos contenido con una presentación excelente que saturar la interfaz.

---

## 3. Cada sección debe tener identidad

Aunque el sitio debe mantener coherencia visual, cada sección puede tener su propia composición, narrativa y movimiento.

No todas las secciones deben parecer tarjetas reutilizadas.

Las páginas públicas deben sentirse diseñadas de forma intencional y no generadas mediante una plantilla genérica.

---

## 4. Las animaciones deben tener propósito

Las animaciones se utilizarán para:

- Guiar la atención.
- Crear profundidad.
- Revelar contenido.
- Resaltar el producto.
- Mejorar la sensación de calidad.
- Construir una narrativa durante el scroll.

Nunca deberán utilizarse únicamente para impresionar.

---

## 5. La experiencia debe ser intuitiva

El usuario debe entender de manera natural:

- Dónde se encuentra.
- Qué puede hacer.
- Cómo regresar.
- Cómo explorar.
- Cómo comparar.
- Cómo consultar un perfume.
- Cómo iniciar la experiencia “Mi Aroma Perfecto”.

---

## 6. La elegancia no debe sacrificar usabilidad

El diseño podrá ser artístico y visualmente impactante, pero deberá mantener:

- Buena legibilidad.
- Contraste suficiente.
- Navegación clara.
- Botones reconocibles.
- Estados de interacción visibles.
- Compatibilidad móvil.
- Accesibilidad.
